# Casino interior sprite assets

These transparent WebP files were cropped from `Rustic casino interior pixel-art sprite atlas.png` without redesigning the supplied artwork.

- `tiles/`: wood flooring and four rug variants
- `architecture/`: wall, corner, doorway, and railing pieces
- `games/`: poker, blackjack, roulette, and slot-machine stations
- `furniture/`: cashier desk, four chair views, and stool
- `decor/`: chips, cards, lamp, plant, and sign

The first casino room uses the core game stations and leaves the remaining pieces available for future room layouts.
